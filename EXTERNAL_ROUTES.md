## Landing page (`/`) — section breakdown

The current stub at `src/app/page.tsx` is 39 lines. Here's a full section map for a proper marketing page. All copy sources are from `docs/product-spec.md` and `README.md`.

### 1. Nav bar

- Left: SubZero wordmark (`SubzeroWithWordmark` from `brand/SubzeroLogo.tsx`)
- Right: Features (anchor), How it works (anchor), Pricing (anchor), Sign in (`/auth?mode=login`), Get started (`/auth?mode=signup`) — CTA button
- Sticky on scroll, blur backdrop

### 2. Hero

- Eyebrow: "AI-powered subscription protection"
- Headline: **"Your subscriptions shouldn't surprise you."** (existing tagline — strong, keep it)
- Sub: "SubZero finds your subscriptions, warns you before renewals, and researches the exact way to cancel — before you're charged."
- Primary CTA: "Find my subscriptions" → `/auth?mode=signup`
- Secondary: "See how it works" → anchor to #how-it-works
- Visual: `mail-mockup.png` from `public/` — the dashboard screenshot showing the attention cards

### 3. Problem strip

- "People don't lose money because they love Netflix. They lose it because trials turn into charges while they're not looking."
- 3 stat cards (real or illustrative):
  - "The average person has 12+ active subscriptions"
  - "Most people don't know their monthly total"
  - "Canceling takes 7–15 minutes per service"

### 4. How it works

4-step horizontal flow (or vertical on mobile):

1. **Connect** — Sign in with Google. SubZero scans your inbox for receipts and trial emails.
2. **Discover** — AI extracts every subscription: merchant, price, renewal date, billing provider.
3. **Research** — Firecrawl finds the current cancellation path for each merchant. Steps, friction level, evidence.
4. **Act** — Clear next step for each one. Open cancellation, open Google Play, review & send email, or contact support.

Each step has a short description and an icon (Hugeicons).

### 5. Features grid

6 feature cards, 2×3 grid:

| Feature | Icon hint | Copy |
|---|---|---|
| **Gmail scan** | inbox/mail | Connect once, SubZero finds every subscription in your inbox automatically. |
| **Renewal alerts** | bell/notification | 7 days, 3 days, 24 hours before — you know what's coming. |
| **Cancel research** | search/magnifier | Step-by-step instructions sourced from each merchant's help pages. |
| **Friction ratings** | gauge/speed | Low to Very High — so you know what you're walking into. |
| **Email forwarding** | forward/mail | Don't want Gmail connected? Forward receipts to your SubZero address. |
| **Evidence trail** | document/shield | Every claim backed by a source quote. If we can't prove it, we don't show it. |

### 6. Comparison: Tracker vs SubZero

Side-by-side or toggle:

| Trackers | SubZero |
|---|---|
| List everything you pay | Surface the 2 that need you this week |
| Show total spend | Show what to do about it |
| Manual entry | Auto-detected from email |
| No cancel guidance | Step-by-step with evidence |
| Static dashboard | Renewal warnings + nudges |

### 7. What it looks like (screenshots)

- `mail-mockup.png` — dashboard with attention cards
- `mail-empty-ui.png` — empty state / onboarding
- Optional: detail view screenshot (evidence + HowToCancel)
- Use `next/image` with remote pattern already configured for `lh3.googleusercontent.com`

### 8. Privacy callout

Full-width dark section:
- "SubZero asks for the least Gmail access it can. We don't copy your whole inbox. We keep only what the feature needs. You can disconnect and delete everything at any time."
- Link to `/privacy`

### 9. CTA banner

- "Find your subscriptions in 60 seconds"
- CTA: "Get started free" → `/auth?mode=signup`
- Secondary: "See how it works" → anchor

### 10. Footer

- Left: SubZero wordmark + "AI-powered subscription protection"
- Center nav: Features, How it works, Pricing, Blog (if exists)
- Right nav: Privacy, Terms, Contact
- Bottom: "Built with Convex" (or omit tech stack — up to brand choice)

## `/features` — deep-dive page

If `/` is the overview, `/features` is the long-form sell. Only needed if the landing page gets too long. Otherwise, anchor sections on `/` may be enough.

Sections:
1. **Email intelligence** — Gmail scan + forwarding + manual. How ingestion works.
2. **Renewal tracking** — Timeline view, upcoming renewals, billing intervals.
3. **Cancel guidance** — The 6 action types, friction ratings, evidence-backed steps.
4. **Smart nudges** — 7d/3d/24h alerts via email, configurable.
5. **Privacy-first** — Gmail scopes, data retention, disconnect.

---

## `/how-it-works` — step-by-step walkthrough

Alternatively an anchor on `/`. Detailed version:

1. Sign in with Google (or forward an email)
2. SubZero scans and extracts subscriptions using AI
3. Each subscription gets researched — cancellation path, friction, evidence
4. You see a dashboard with clear next steps
5. Take action — one click to cancel, or step-by-step guide
6. SubZero tracks status and confirms when you're done

## SEO infrastructure

## 404 improvements

Current `NotFoundView` links to `/dashboard`. For unauthenticated users hitting a bad URL on the marketing site, it should:
- Link to `/` instead of `/dashboard`
- Add a "Go home" button alongside "Back to Dashboard"
- Only show "Back to Dashboard" if user is authenticated (check auth state)
